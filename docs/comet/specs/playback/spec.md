# Capability: playback — 播放核心

前端播放控制、播放队列与状态记忆能力。

## controls — 播放控制与播放模式

- 基础控制：播放/暂停切换、上一首、下一首。
- 进度条：显示当前时间/总时长，可点击或拖动定位（seek）。
- 音量：音量滑块调节（0-100），静音切换按钮；音量变化即时生效。
- 播放模式三选一切换：列表循环（默认）、单曲循环、随机播放。
  - 列表循环：播完当前曲自动播队列下一首，到末尾回到开头。
  - 单曲循环：当前曲结束后重新播放本曲。
  - 随机播放：播完随机选择队列中另一首（不连续重复同一首，队列长度>1 时）。
- 当前播放曲目在曲库列表与队列中高亮显示。
- 切换歌曲时更新页面标题与底部播放条信息（标题、艺术家）。

## queue — 播放队列

- 当前播放列表即播放队列；点击曲库中的歌曲或"播放全部"会构建队列并开始播放。
- 队列面板：展示队列内所有曲目与当前播放项；支持点击某项立即播放、移除单曲、清空队列。
- 移除当前播放曲目时自动播放下一首；清空队列停止播放。

## persistence — 播放状态记忆

- 使用 localStorage 持久化：当前曲目 id、播放进度（秒）、音量、播放模式、队列内容。
- 页面加载时恢复：重建队列、定位到记忆进度（不自动播放，等待用户点击）、恢复音量与模式。
- 播放过程中节流保存进度（约每 5 秒），避免频繁写入。
