# Capability: app-ui — Apple Music 式极简界面

前端的极简视觉与响应式布局能力。功能逻辑不变（由 playback/playlists/lyrics/music-library 能力承载），本能力定义视觉风格、主题系统与设备适配。

## theme — 主题三态与记忆

- 三态主题：浅色（light）、深色（dark）、跟随系统（auto，默认）。
- auto 模式下监听 `prefers-color-scheme`，系统偏好变化时实时切换，无需刷新。
- 主题选择持久化到 localStorage，刷新后恢复；手动切换入口位于顶栏。
- 视觉基调（Apple Music 式极简）：
  - 浅色：近白背景（#f5f5f7 系）、深色文字、强调色 #fa2d48（Apple Music 红）或系统蓝点缀
  - 深色：纯黑/近黑背景（#121212 系）、浅色文字、同一强调色
  - 大圆角（12px+）、无衬线系统字体、克制的分隔线与阴影、充足留白
  - 播放控件为圆形按钮，主播放按钮为强调色实心圆
- 所有颜色通过 CSS 变量定义，主题切换只切换变量，不改结构。

## responsive — 响应式布局

- 断点：≥900px 为桌面布局，<900px 为移动布局。
- 桌面布局：左侧导航栏（曲库目录、歌单、上传）+ 中间曲目列表 + 右侧面板（队列/歌词 tab）+ 底部播放条；整体为圆角卡片式分区。
- 移动布局：
  - 底部标签栏：曲库 / 歌单 / 队列 三个 tab
  - 迷你播放条：悬浮于标签栏上方，显示当前曲目标题与播放/暂停按钮，点击展开全屏播放页
  - 全屏播放页：大标题、播放控制、进度条、歌词入口、队列入口，下滑或点关闭按钮收起
  - 搜索、上传、歌单管理、主题切换在移动端均可达
- 布局切换不丢失播放状态（audio 元素全局唯一，不随布局重建）。

## parity — 功能无回归

- UI 重构后，以下既有功能在桌面与移动端均保持可用：
  - 播放控制（播放/暂停/上下首/进度/音量/静音/播放模式）
  - 播放队列（展示/点击播放/移除/清空）
  - 歌单（新建/重命名/删除/加曲/播放歌单）
  - 歌词（渲染/同步高亮/点击跳转）
  - 搜索过滤、目录分组浏览、网页上传
  - 播放状态记忆（localStorage 键与语义不变）
- 后端 API 不变，无服务端改动。
