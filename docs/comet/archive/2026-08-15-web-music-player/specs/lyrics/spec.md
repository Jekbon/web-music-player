# Capability: lyrics — 歌词解析与同步显示

## parser — LRC 解析（前端 + 单元测试覆盖）

- 解析 LRC 文本为 `[{ time: 秒, text: 歌词行 }]` 数组，按时间升序排序。
- 支持 `[mm:ss.xx]` 与 `[mm:ss.xxx]` 时间戳；支持一行多时间戳（`[00:12.00][00:34.00]同一句`）展开为多条。
- 忽略元数据标签（[ti:]、[ar:]、[al:]、[by:]、[offset:] 等）与无法解析的行。
- 支持 offset 元数据整体偏移（正值提前）。

## display — 同步显示与交互

- 切换歌曲时请求 `GET /api/lyrics/:id`；有歌词时渲染歌词面板，无歌词时显示"暂无歌词"占位。
- 播放过程中按当前进度高亮对应歌词行，歌词区自动滚动保持当前行可见。
- 点击歌词行跳转到该时间点播放。
