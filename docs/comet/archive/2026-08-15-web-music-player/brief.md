# Outcome

个人使用的 Web 音乐播放器：浏览器访问，播放服务器上的音乐。支持本地目录扫描与网页上传两种音乐来源，具备完整播放控制、播放队列与歌单、播放模式、歌词同步显示、搜索过滤与播放状态记忆；单命令启动，局域网直接访问。

# Scope

1. 音乐库：递归扫描可配置的本地音乐目录，支持 mp3/m4a/ogg/wav/flac；解析 ID3v2 元数据（标题/艺术家/专辑），缺失时回退文件名；支持网页上传音频文件入库；支持删除歌曲（物理删除磁盘文件）
2. 曲库浏览：按目录结构分组展示；按歌名/艺术家/路径关键字搜索过滤
3. 播放核心：播放/暂停、上一首/下一首、进度条拖动定位、音量调节与静音、播放模式（列表循环/单曲循环/随机播放）、播完自动续播
4. 播放队列：当前播放列表即队列，队列面板展示、移除单曲、清空队列、点击队列项播放
5. 歌单：创建/重命名/删除歌单，添加/移除歌曲，播放整个歌单，歌单服务端持久化
6. 歌词：自动匹配同名 .lrc 文件，解析展示、逐行同步高亮、点击歌词行跳转进度
7. 状态记忆：localStorage 记忆上次播放歌曲、进度位置、音量、播放模式，刷新后恢复
8. 部署访问：单命令启动，http://ip:port 直接访问，无登录

# Non-goals

- 不做音频转码或格式转换（依赖浏览器原生解码；flac/wav 在个别浏览器可能无法播放）
- 不做多用户/账户体系与访问控制（仅面向可信局域网环境）
- 不做移动端原生 App、不做 PWA 离线缓存
- 不接入在线曲库或第三方音乐服务
- 不做封面上传、标签修改、文件删除等曲库编辑功能
- 不做 HTTPS/反向代理配置（如有需要用户可自行加装）

# Acceptance examples

- 单元测试：LRC 解析器正确解析 [mm:ss.xx] / [mm:ss.xxx] 时间戳与歌词文本，支持一行多时间戳，忽略元数据标签与畸形行
- 单元测试：ID3v2 解析器从带标签 mp3 正确提取标题/艺术家/专辑（TIT2/TPE1/TALB）；无标签或解析失败时回退文件名
- 单元测试：multipart 解析器正确切分上传文件二进制内容与表单字段
- 单元测试：曲库扫描器递归扫描目录，仅收录白名单后缀（大小写不敏感），忽略隐藏文件与隐藏目录
- 集成测试：GET /api/library 返回曲目列表，含 id/title/artist/album/folder/path 字段，JSON 结构符合规格
- 集成测试：GET /api/stream/:id 支持 HTTP Range 请求返回 206 与正确 Content-Range；无 Range 返回 200 完整内容；未知 id 返回 404
- 集成测试：POST /api/upload 上传 mp3 成功并出现在曲库中；非白名单后缀被拒绝返回 400
- 集成测试：歌单 API 支持创建、列表、添加歌曲、移除歌曲、重命名、删除，数据落盘且服务重启后仍在
- 集成测试：DELETE /api/tracks/:id 物理删除音频文件（连同同名 .lrc），曲目从曲库消失，歌单中对应引用被清理；未知 id 返回 404；拒绝删除音乐目录之外的路径
- 实测：曲目行菜单删除歌曲，确认后文件被删除、列表即时更新；删除正在播放的歌曲自动切换下一首
- 集成测试：GET /api/lyrics/:id 在同名 .lrc 存在时返回歌词文本，不存在时返回空标记
- 实测：浏览器打开页面，曲库分组列表正确渲染，点击歌曲可播放，播放/暂停/上一首/下一首/拖动进度/音量/静音/播放模式切换均生效
- 实测：队列面板展示当前队列，支持点击播放、移除单曲、清空队列
- 实测：刷新页面后恢复上次歌曲、进度位置、音量与播放模式
- 实测：搜索框输入关键字可过滤歌曲；播放时歌词当前行同步高亮，点击歌词行跳转进度

# Constraints and invariants

- Node.js 22 运行；服务端不引入第三方运行时依赖（仅用原生 http/fs/path/crypto）
- 前端为原生 HTML/CSS/JS 单页，无构建步骤、无 CDN 依赖（离线可用）
- 音乐目录默认项目下 ./music，可经环境变量 MUSIC_DIR 配置；上传只允许写入该目录，必须防止路径穿越
- 流式端点必须支持 HTTP Range（进度拖动依赖）
- 歌单数据持久化到 data/playlists.json
- 无登录鉴权，服务仅面向可信本机/局域网环境

# Decisions

- D1 音乐来源：本地目录扫描 + 网页上传，两者都要（用户确认：该有的都有，按完整标配）
- D2 格式支持：mp3/m4a/ogg/wav/flac 直出，不做转码
- D3 播放功能集：基础控制 + 播放队列/歌单 + 播放模式 + 歌词显示，全部包含
- D4 曲库组织：按目录结构分组浏览，有 ID3 元数据时展示标题/艺术家/专辑
- D5 状态记忆：需要，存浏览器 localStorage
- D6 搜索：需要，按歌名/艺术家/路径关键字过滤
- D7 部署：局域网 http://ip:port 直接访问，无登录
- D8 技术方案（选型）：A 纯前端方案（File System Access API，无服务端）——无法扫描服务器目录、无法上传，淘汰；B Node 原生 http 轻量后端 + 原生 JS 单页前端——零依赖、无构建、简单可靠，采用；C React/Vue 全栈 + 构建工具链——个人使用过重，淘汰
- D9 UI 配色：浅色 + 深色 + 跟随系统自动切换，手动可切且记忆（用户确认："我全都要"）
- D10 功能取舍：全部功能保留，极简仅体现在视觉与布局（用户确认："我全都要"）
- D11 设备适配：响应式，桌面 + 移动端都适配（用户确认："我全都要"）
- D12 UI 风格基准：Apple Music 式极简（大圆角、无衬线字体、强调色点缀、克制的阴影与分隔线）
